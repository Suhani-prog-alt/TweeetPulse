# 🐦 TweeetPulse

A Twitter-inspired full-stack web application where users can post, view, and interact with tweets in real time.

## 🚀 Features

- 📝 Create and post tweets
- 🗂️ View tweet feed with all posts
- 👤 User model with profile support
- 🎨 Clean and responsive UI

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | EJS, CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB (Mongoose) |
| Templating | EJS (Embedded JavaScript) |

## 📁 Project Structure

```
TweeetPulse/
├── models/           # Mongoose schemas (User, Tweet)
├── routes/           # Express route handlers
├── views/            # EJS templates
├── public/
│   └── stylesheets/  # CSS styling
├── app.js            # Entry point
└── package.json
```

## ⚙️ Getting Started

### Prerequisites
- Node.js installed
- MongoDB running locally or MongoDB Atlas URI

### Installation

```bash
# Clone the repo
git clone https://github.com/Suhani-prog-alt/TweeetPulse.git

# Navigate into the project
cd TweeetPulse

# Install dependencies
npm install

# Start the server
node app.js
```

Open your browser at `http://localhost:3000`
